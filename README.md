# Noor & Co. — Vanilla HTML/CSS/JS demo (core build)
Run: open the folder in VS Code, install "Live Server", right-click index.html > Open with Live Server. No build step, no frameworks.
Built: shared header/footer (js/main.js), homepage, shop (filters, sort, load-more), product page (variants, qty, wishlist, WhatsApp, related, recently viewed), cart (coupons NOOR10 / WELCOME15, sample shipping), localStorage persistence, 24 sample products.
Placeholder pages (linked, not yet built): all other storefront pages and admin/*. Simulated: everything; WhatsApp number is a placeholder in js/main.js.
Images: only the 2 supplied photos are local; other products show tonal placeholders. Add files to assets/images and set `image` in js/products.js.
